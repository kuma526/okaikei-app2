# 個人事業主向け 出納帳 Webアプリケーション

スマートフォンやタブレットのブラウザから手軽に入力できる、レスポンシブな個人事業主専用の出納帳・会計Webアプリケーションです。

---

## 🌟 主な機能と特徴

### 1. 収支・売上・仕入れの高速記帳
- **収入項目**: 「Uber」売上振込、「Rocket Now」売上振込、その他手動売上
- **支出項目**: 仕入れ（レシート・伝票）、銀行振込、その他経費
- **銀行管理**: 手元現金と銀行口座間の「預金入金」「預金出金」専用カード

### 2. レシート画像保存 ＆ AI / OCR 解析（品目・勘定科目の自動推測）
- スマートフォンのカメラで撮影したレシート・伝票・銀行明細画像をその場でアップロード＆保存。
- **Gemini API** を利用して画像から「合計金額」だけでなく**「購入品目リスト」**を詳細に読み取り。
- 読み取った品目や店舗の種類から、確定申告（青色・白色）に適した**勘定科目（仕入高、消耗品費、旅費交通費、通信費、会議費など）をAIが自動推測してフォームに自動反映**。
- AIの推測結果は、画面上のドロップダウンから**いつでも手動でワンタップ修正可能**です。

### 3. Google カレンダー連携（日次収支の終日イベント同期）
- 1日の収支合計（収入・支出・差引手取収支）を、Googleカレンダーの**非公開予定（終日イベント）**として自動同期・書き込み。
- イベント本文には Uber/Rocket Now 売上や仕入高・経費の内訳が自動記載されます。
- 画面上の「本日の収支を同期」「今月分を一括同期」ボタンに加え、付属の `scripts/sync_calendar.py` を Windows タスクスケジューラに登録して**毎晩自動実行するバッチ処理**にも対応しています。

### 4. ワンクリック帳票エクスポート
- 📗 **Excel 出力 (.xlsx)**:
  - Sheet 1: 月次損益サマリー（総収入、総支出、粗利益カード、Uber/Rocket Now別集計、勘定科目別構成比）
  - Sheet 2: 全取引明細一覧（カラー見出し、通貨フォーマット、レシート有無付き）
- 📕 **税務確認用 PDF 集計表 (.pdf)**:
  - 確定申告書・青色申告決算書スタイルの月次損益計算書（売上高、売上原価/仕入高、差引売上総利益、経費内訳、所得金額）
  - 日本語フォント対応
- 📘 **マネーフォワード クラウド形式 CSV**:
  - MFクラウド確定申告の「仕訳帳」インポートにそのまま取り込める形式
- 📙 **弥生会計 / やよいの青色申告形式 CSV**:
  - 弥生会計の仕訳データインポート形式 (cp932)

## 🚀 クイックスタート

### 起動方法
フォルダ内の **`run.bat` をダブルクリック** するだけで自動起動します。

```bash
# コマンドラインから起動する場合
.venv\Scripts\python.exe main.py
```

### ブラウザで開く
- **PCから利用**: [http://localhost:8000](http://localhost:8000)
- **スマートフォン・タブレットから利用**:
  PCと同一のWi-Fiに接続し、スマホのブラウザ（Safari / Chrome）で以下を開きます：
  ```
  http://[PCのIPアドレス]:8000
  ```
  *(例: `http://192.168.1.15:8000`)*
  > **スマホでの便利な使い方**: ブラウザのメニューから「ホーム画面に追加」を行うと、ネイティブアプリ感覚でワンタップ起動できます。

## ⚙️ 外部連携の設定（Googleドライブ・Googleカレンダー）

### A. Google ドライブ自動保存の設定
アップロードされたレシート・領収書画像は、ご指定のGoogleドライブフォルダ（`1qX_mCHjCEFKQoGfuoMrIxJvOZIpWibq8`）に自動転送・保存されます。

**【連携を有効化する手順】**:
1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成（または既存プロジェクトを選択）し、「**Google Drive API**」を有効化します。
2. 「認証情報」から「**サービス アカウント**」を作成し、キー（JSONファイル）を作成・ダウンロードします。
3. ダウンロードした JSON ファイルを当プロジェクトのフォルダ直下に **`credentials.json`**（または `service_account.json`）という名前で配置します。
4. ご指定のGoogleドライブフォルダ（[フォルダリンク](https://drive.google.com/drive/folders/1qX_mCHjCEFKQoGfuoMrIxJvOZIpWibq8?usp=sharing)）を開き、右上の「共有」から、サービスアカウントのメールアドレス（`xxxx@xxxx.iam.gserviceaccount.com`）を「**編集者**」として追加します。
5. これで、レシートをアップロードした瞬間に自動的にあなたのGoogleドライブフォルダ内へ保存されるようになります！

### B. Google カレンダー連携の設定
1. Google Cloud Console で「Google Calendar API」を有効化し、サービスアカウントキー（またはOAuthクライアントID）をダウンロードします。
2. ダウンロードした JSON ファイルをプロジェクト直下に `credentials.json` として配置します。
3. アプリ上の「カレンダー」タブから「同期」を実行すると、Googleカレンダーに反映されます。
   *(※認証ファイル未配置の場合でも、登録されるイベント内容のプレビュー機能が動作します)*

### C. カレンダー同期の自動バッチ化（タスクスケジューラ）
Windowsの「タスク スケジューラ」で新しいタスクを作成し：
- プログラム: `C:\Users\subef\OneDrive\ドキュメント\会計ソフト\.venv\Scripts\python.exe`
- 引数: `scripts/sync_calendar.py`
- 開始（ディレクトリ）: `C:\Users\subef\OneDrive\ドキュメント\会計ソフト`
- トリガー: 毎日 23:30
と設定することで、毎晩の自動同期が実現します。
