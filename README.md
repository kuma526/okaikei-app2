# 勘太郎 ver. 1.0 - 個人事業主向け 出納帳 Webアプリケーション

スマートフォンやタブレットのブラウザから手軽に入力できる、レスポンシブな個人事業主専用の出納帳・会計Webアプリケーションです。
Googleの認証設定なしで、Render等のクラウド環境へ即座にデプロイしてスマホから利用できます。

---

## 🌟 主な機能と特徴

### 1. 収支・売上・仕入れの高速記帳
- **売上・収入セクション**:
  1. **店舗売上**: 現金（直接入力メモ）および「楽天ターミナル」（カード / QRコード / 電子マネー選択＋カード決済手数料自動計算）に対応
  2. **UBER振込**: 配達報酬売上振込の自動仕訳
  3. **ROCKET NOW振込**: 即時出金・デリバリー売上振込
  4. **その他売上**: 手動・自由売上
- **カード決済手数料の自動計算**:
  - 楽天ターミナル等のカード売上時、設定された手数料率（例: 3.24% または 3%、指定可能）を自動計算
  - 「売上総額」「引かれた手数料」「実際の振込・受取額」の内訳をリアルタイム表示し、メモ欄および出納帳データへ自動記録
- **支出・仕入れセクション**:
  - 決済方法として従来の銀行口座に加え、「**カード決済**」「**QRコード支払い**」にも対応
- **銀行管理**: 手元現金と銀行口座間の「預金入金」「預金出金」専用カード
- **品目・摘要メモのプルダウン**: 勘定科目に応じたよく使う品目候補からワンタップで選択＆編集可能（店舗現金売上時は直接入力に自動切替）

### 2. レシート・領収書 画像保存
- スマホのカメラで撮影または写真を選択して、0.1秒で即座にサーバーへ保存。
- スマホ撮影特有の回転ズレ（EXIF Orientation）も自動で正立補正。
- 保存したレシート画像は一覧画面からいつでも高画質に確認・ダウンロード可能。

### 3. ワンクリック帳票エクスポート
- 📗 **Excel 出力 (.xlsx)**:
  - Sheet 1: 月次損益サマリー（総収入、総支出、粗利益カード、Uber/Rocket Now別集計、勘定科目別構成比）
  - Sheet 2: 全取引明細一覧（カラー見出し、通貨フォーマット、レシート有無付き）
- 📕 **税務確認用 PDF 集計表 (.pdf)**:
  - 確定申告書・青色申告決算書スタイルの月次損益計算書（売上高、売上原価/仕入高、差引売上総利益、経費内訳、所得金額）
  - クラウド環境（Render/Linux）でも文字化けしない日本語フォント内蔵
- 📘 **マネーフォワード クラウド形式 CSV**:
  - MFクラウド確定申告の「仕訳帳」インポートにそのまま取り込める形式
- 📙 **弥生会計 / やよいの青色申告形式 CSV**:
  - 弥生会計の仕訳データインポート形式 (cp932)

## 🚀 クイックスタート (ローカルPCで動かす)

### 起動方法
フォルダ内の **`run.bat` をダブルクリック** するだけで自動起動します。

```bash
# コマンドラインから起動する場合
.venv\Scripts\python.exe main.py
```

### ブラウザで開く
- **PCから利用**: [http://localhost:8000](http://localhost:8000)
- **スマートフォン・タブレットから利用 (同一Wi-Fi内)**:
  スマホのブラウザで `http://[PCのIPアドレス]:8000` を開きます。

## ☁️ Render への無料デプロイ手順 (スマホで外出先から使う)

Google連携などの認証キー設定が一切不要なため、GitHubにアップロードしてRenderを接続するだけでデプロイできます。

### 1. GitHub にリポジトリを作成してプッシュ
```powershell
$env:Path = "C:\Program Files\Git\cmd;$env:Path"
git add .
git commit -m "Update kaikei app"
git push -u origin main
```

### 2. Render で Web Service を作成
1. [Render](https://render.com/) にアクセスし、GitHubアカウントでログイン。
2. 「**New +**」→「**Web Service**」を選択。
3. リポジトリを選んで、以下のように設定（`render.yaml` があるため基本は自動入力されます）：
   - **Runtime**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python -m uvicorn backend.app:app --host 0.0.0.0 --port $PORT`
     *(※ `uvicorn: command not found` を防ぐため `python -m uvicorn` を指定します)*
   - **Instance Type**: `Free`
   - **Environment Variables**: **何も入力不要（空でOK）**
4. 「**Create Web Service**」をクリック。
5. 2〜3分でビルドが完了し、専用URL（`https://xxxx.onrender.com`）が発行されます。スマホのブラウザで開いて「ホーム画面に追加」すれば完了です！
